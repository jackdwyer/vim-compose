# Vim Compose

⌥Space / Ctrl+Space in a `<textarea>` → vim opens → `:w` syncs to the page → `:q` done.

## Setup (macOS + Firefox)

1. `git clone https://github.com/jackdwyer/vim-compose && cd vim-compose`
2. `./install-native-host`  *(needs vim, [pandoc](https://pandoc.org), [Alacritty](https://alacritty.org/), [rust](https://rustup.rs/))*
3. Install the [extension from AMO](https://addons.mozilla.org/firefox/addon/vim-compose/), restart Firefox
